## How to improve a row

1. Identify an authorized Forest source.
2. Preserve the original visible excerpt in the Book layer without rewriting it.
3. Assign a `BOK-####` ID.
4. Map the exact Rendering line or segment to that passage.
5. Record whether the Rendering is verbatim, lightly edited, compiled, reordered, or newly written.
6. Attach the strongest justified P-rank and source-distance label.
7. Obtain a second review before calling the row complete.

Never use hidden reasoning or an unauthorized transcript body to close a concordance gap.
