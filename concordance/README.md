# Concordance

Concordance is Blobness's mapping shelf. Each named Book receives a matching folder when sources, passages, renderings, motifs, claims, permissions, or corrections need explicit cross-references.

[`book-of-prism/`](book-of-prism/) demonstrates a concordance that preserves a Rendering exactly while leaving unresolved transcript-level genealogy visible.

A concordance is allowed to say `PENDING`, `UNVERIFIED`, `WITHHELD`, or `NO PUBLIC SOURCE`. Its job is to expose the map honestly, not to make every route appear complete.
