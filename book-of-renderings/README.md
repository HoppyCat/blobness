# Book of Renderings

This shelf holds transformed works: plays, essays, scenes, songs, illustrations, syntheses, documentary sequences, and other adaptations.

Each Rendering belongs beneath the same named Book slug used in Forest, Book of Blobness, and Concordance. [`book-of-prism/`](book-of-prism/) contains the first example.

A Rendering may be beautiful, exact to a prior artifact, and culturally meaningful while its underlying event provenance remains partial. Rendering fidelity and event provenance must be reported separately.
