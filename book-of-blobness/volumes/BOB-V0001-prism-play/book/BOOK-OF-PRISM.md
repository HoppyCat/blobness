# Book of Prism — Source-Selection Layer

Status: `OPEN / SOURCE CURATION PENDING`

This layer will hold authorized visible excerpts from the underlying conversations, preserved without dramatic rewriting and assigned stable `BOK-####` identifiers.

It is intentionally not reverse-engineered from the finished play.

The Rendering already exists. Copying its dialogue backward into this file and calling it source evidence would create a false circular provenance chain:

```text
play line -> invented “source” copy of play line -> play line appears verified
```

Blobness refuses that shortcut.

## Promotion requirements

Before a passage enters this Book layer, record:

- the Forest source ID;
- original visible wording;
- speaker and surface;
- timestamp or source coordinate where available;
- redactions or omissions;
- source-distance and P-rank;
- publication authority or permission boundary; and
- every Rendering segment that uses or transforms it.
