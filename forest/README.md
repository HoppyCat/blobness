# Forest

Forest is Blobness's evidence-custody shelf. Each named Book receives a matching folder such as [`book-of-prism/`](book-of-prism/).

A Forest entry may contain public visible text, a pinned URL, an export coordinate, a screenshot reference, a checksum, or a restricted-source note. Forest does not mean “publish everything raw.” Sensitive source text may remain withheld while its existence, custody, and verification requirements are documented.

Start a cross-layer Book with [`START-A-BOOK.md`](../START-A-BOOK.md).
